# Campus Lost & Found

A polished, responsive, dependency-free MVP for university lost & found reporting.

**This is just a 60 min rapid prototype only, not a finalized web application.**

## Project structure
- `index.html` — page markup and navigation structure
- `styles.css` — all styling, theme, cards, forms, and responsive rules
- `app.js` — demo data, state, rendering, search/filtering, navigation, and form submission

## Run
Open `index.html` directly in a modern browser. No server, authentication, backend, API, or build step is required.

## Included
- Home dashboard and statistics
- Browse/search/filter
- Item details + recovery/contact demo info
- Lost/found reporting form
- LocalStorage persistence
- My Reports
- Responsive mobile navigation
- Back navigation
- Fictional demo data and contacts
